Only reference core, portable compression, headers and license are included.
No upstream application, encoder, thread implementation or build-time download.
All linked private symbols are prefixed sb_argon2_. The owning native adapter
does not call upstream allocation, initialization or finalization entrypoints.
It uses caller-owned workspace, input and output, and synchronous lane traversal.

Local changes:
- ref.c/core.h: callback-based bounded interruption every64 memory blocks;
  callbacks return through C normally before an exception is rethrown in C++.
- ref.c: erase block/segment scratch on success and interruption.
- core.c: unconditional scratch erasure; no global erasure-disable switch.
- blake2b.c: erase compression and variable-output temporary buffers.
Algorithm version0x13, indexing and compression permutations are unchanged.
