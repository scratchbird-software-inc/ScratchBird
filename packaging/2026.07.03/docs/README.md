# ScratchBird 2026.07.03 Package Documentation

This directory contains operator documentation for the 2026.07.03 pre-release
package tree.

- `linux-opt-installation.md` describes a full Linux layout under
  `/opt/ScratchBird`, including server, listener, manager, SBParser, tools,
  drivers, adapters, UDR payloads, and shared resources.
- `etc-configuration.md` describes the host configuration layout under
  `/etc/scratchbird` and how it relates to the package-owned files under
  `/opt/ScratchBird`.
- `default-policy-pack.md` describes every default policy family, seeded
  setting, default value, and runtime surface that uses the setting.

This package is a pre-release staging tree for installer construction and beta
testing. It is not an official release installer.
